# Comando: Build Services Page

## Instrução para o Cursor

Crie o arquivo `pages/servicos.html` com:

### Estrutura
- Mesmo header/footer da home

- Hero interno:
  - Título: "Nossos Serviços"
  - Subtítulo: "Serviços notariais e de registro com agilidade e transparência"

- Lista completa de serviços (expansível):
  
  **Tabelionato de Notas**
  - Procuração Pública
  - Autenticação de Documentos
  - Reconhecimento de Firma
  - Testamentos (público e cerrado)

  **Registro Civil**
  - Nascimento (1ª via e 2ª via)
  - Casamento
  - Óbito
  - Averbações

  **Protesto de Títulos**
  - Protesto de dívidas
  - Cancelamento de protesto
  - Certidão de protesto

  **Registro de Títulos e Documentos**
  - Contratos
  - Documentos particulares

### Para cada serviço
- Card individual
- Ícone correspondente
- Descrição em 1 linha
- Botão "Solicitar via WhatsApp"

### Extra
- Seção "Documentos necessários" (tabela simples)
- Badge "Urgente" para serviços que aceitam pedido rápido

### Diferencial solicitado
- Toque regional: mencionar "Atendimento para Picos, Santana do Piauí, Sussuapara, Geminiano e Aroeira do Itaim"
